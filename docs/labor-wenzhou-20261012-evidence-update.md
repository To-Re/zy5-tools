# 温州工资规则补证与浙江养老金可实现范围

核验日：2026-10-12。仅研究，不修改生产规则、代码或部署。本报告补充并更新 `labor-wenzhou-medical-followup.md` 和 `labor-zhejiang-auto-flow-research.md` 中“未取得2022医保正式全文”的旧状态；未闭合的2026配套冲突仍保留。

## 结论与准入次序

1. 本轮取得温政办〔2022〕86号完整正式医保办法，首次把个人2%、上年月均口径、单位含生育9.2%的基础法源闭合。**仍不能直接注册为2026完整医保包**：存在2025/2026统筹配套文件线索，尚未读到全文；需要排除相应条款替代及核定2026医疗基数上下限。
2. 个人医疗可准备独立字段 `approvedMedicalBaseCents` × 200 bps、仅乘积恰到分的复核能力；须在配套冲突核查完成后开放。不要把养老上下限套到医疗；不要把此分项称个人医保全部扣款。
3. 已有养老及公积金情景仍可使用。工资首屏“城市＋月薪”可以采用显式的“上年月均工资等于本月”假设；实际申报基数不能标成已核定。完整到手/成本继续阻断，失业单位费率未知不填0。
4. 浙江养老金普通新人可以继续省统一基础/账户分项复核；完整总額仍需省级调节金当期参数、最低补足和当前舍入链。不能因为缺温州重复发布而阻断省级统一分项。

## 追加突破：普通中人的基础分项不必限制在新人28年

2026-10-12本轮重新用Chrome读取浙劳社老〔2006〕142号完整官网正文（上表同URL，网页有效，成文2006-09-19、实施2006-01-01，网页迁移发布日期2014-02-24）。第15(1)明确中人的基础养老金及个人账户养老金公式与第14条相同；第15(2)另列过渡性养老金。因此可以在独立审核后，将**浙江基础独立分项复核**扩为普通新人/中人，经办已核定当前该公式及全部I/Y，可接受40年等合理核定年限。40年属于产品技术范围，不是本文设定法定上限。

准入必须同步修改population：不能一边允许40年、一边仍称“1998后首次参保、无视同、无过渡”。应表达“普通企业职工，经办已核定按第14/15条基础公式；本工具仅复核基础分项，不计算过渡、调节金、补贴、最低保障或总额”。经办核定的视同替代指数可以已反映在I中，工具不自行推导视同指数。

明确排除第17条“双低”办法：其基础养老金还要乘缴费系数，普通公式不能套。排除第19条2005年底以前已退休按旧办法、第20—21条历史过渡期新老比较重算；退职、特殊历史批准公式继续不在首域。第23条一次性荣誉/特殊工种补贴不并入基础分项。年限按第18条计月、指数四位，尾差仍仅接受精确至角的结果，保留原有精度闸门。第22条断缴分母/视同替代指数由经办核定，不能通过扩大年限顺便自动重建历史。

例如S8537、I1、Y40，独立基础算式为3414.8元；这是基础分项，不是该中人的养老金总额。本追加已经同步root、engine和independent_audit；未修改生产规则。
