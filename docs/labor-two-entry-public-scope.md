# 两入口对外文案与实际支持边界

核验日期：2026-10-12。本版本支持范围；生产版本以部署记录为准。

建议主描述：**按已核官方规则核对个人缴费与单位成本，在限定范围内比较固定参数下的税后收入和退休方案。资料或规则不足时显示缺项。**

## 社保退休金测算

建议紧邻入口写：**养老金金额及目标倒推目前仅支持上海限定情景；跨省记录只作有条件的领取省核对，不拼算各地养老金。固定规则金额不是未来待遇承诺。**

| 能力 | 实际前提与边界 |
| --- | --- |
| 法定退休年月 | 出生年月与档案确认的原50/55/60岁类别；不能仅凭性别推定。原类别法定时间，不规划弹性提前/延后或特殊退休。 |
| 领取省 | 需完整已核历史、户籍、普通养老关系与明确未来状态；按户籍关系、当前省累计十年、最后满十年省等顺序有条件核对。只到省级；不认定市级经办地、临时账户或未来跨省转移后新关系。 |
| 金额正算 | 只支持上海同省、1993年起普通实际缴费；2014年前须另行确认经办指数和已处理2026附件历史保底；无视同、过渡、特殊身份等。历史须有完整认可月数、经办核定逐月四位缴费指数之和（不能用已修约平均数反推），账户余额截至2026-09。历史现金实缴可未知，但图表累计只能称已录入部分。 |
| 精确计算子域 | 原退休类别法定退休时为50—66整岁；未来基数支持7546—37731元整元，累计月数不再限3的倍数。四位月指数及折年取舍计算相邻上下界，最终分项进角一致才给确定金额，否则只给待核范围。整元/整岁仍是产品子集。 |
| 未来假设 | 2026-10起，冻结2026规则、12577元社平/指数分母、增长0、账户未来利息0；退休月办妥手续，次月开始领取。未知未来月份不自动停缴，需明确选择。 |
| 职工与灵活就业 | 职工现金个人8%、单位16%；灵活本人现金20%、账户入账8%，不能混算。灵活情景仅原60岁类别且独立确认符合当前上海参保准入；退休月缴费还需此前已满足最低年限。 |
| 按目标倒推 | 历史、账户、出生/类别、户籍/关系固定。只求“固定基数下连续缴多久”或“固定窗口下整元基数最低多少”，受月预算及法定退休月限制。采用时替换未来计划并明确其余未来月份停缴。 |
| 倒推解释 | 不同时优化年月和金额、不跨省择优、不延迟退休；代表性候选不穷举展示全部方案。无解及最高可达只对本次已覆盖整元/月数搜索域成立；取舍敏感另列诊断，资料不足是未知，不是无解。目标2000/10000/20000只是预填目标。 |
| 累计图 | 领取年数是累计观察窗口，不是停发时间或计发月数。个人/单位养老现金及账户权益分开，其他险种和公积金不混入养老图。 |

基础分项复核另支持北京、浙江（含温州）经办核定的标准 `B × 全部年限 × 1%`，显式确认后可含普通中人和已认定视同，不限15—28年；双低等特殊公式、过渡项目和总额仍不计算。账户分项范围不随之扩大。

## 工资测算

主结果默认是**固定2026-10规则重复12期的年均净现金情景**，不称本月实发、实际2026全年税款或汇算结果。实际累计预扣、税后反推和年度汇算另有明确输入与适用规则，不能用默认情景替代累计背景。

| 地区 | 可以做什么 | 不能据此声称什么 |
| --- | --- | --- |
| 上海 | 普通税后情景当前月薪支持分、2025年月均工资暂支持整元，按已核下限/上限映射，公积金各5/6/7%；逐项乘积须满足已核精度，个人缴费不能超过工资；无补充公积金、特殊减免、其他收入/扣除，另设基数不开放税后。万元/5%例年均8315元。 | 单位失业及工伤规则缺项，不能出完整公司成本。失业缴费出现半分或公积金非整元时相应项目拒算，不猜地方舍入；这不是法定工资限制，也不是实际月预扣。 |
| 北京 | 已核普通缴费子域可核个人和单位费用；完整标准公司成本需确认本期最终工伤费率并满足各项精确规则。万元/5%/工伤0.2%的虚构例成本13150元。固定12期净额只在保守上界严格证明零税时开放（4500/5%虚构例3508.65元）。 | 不支持一般北京工资税后全域；上界证明失败不是断言实际要缴税。标准成本不自动包含未填福利等所有会计成本；工伤率默认未知。 |
| 温州 | 部分已核缴费项目。 | 不提供完整五险一金、税后或公司成本。 |

城市和工资初始为空；上年均薪暂同当月、公积金5%均为界面明示的可调整方案假设，不是法定默认。所有输入仅页面内存，不上传或持久化。

## 必须避免的宣传

- “全国养老金计算”“北上浙完整覆盖”“输入城市工资就知道真实到手”。
- “某地缴满若干年保证月领某金额”“2000/10000/20000元保证方案”。
- “所有合法方案无解/最高待遇/唯一最优”，或把未知资料输出为0。
- 将仍保留的实现精度子集（整岁、整元基数）说成法律仅允许这些情况；三月倍数与三档限制已移除。

界面仅减少默认展示的重复来源。每结果保留专属依据入口，展开后可核公式、地区/人群、适用期、核验日及完整官方链接。短声明可见，长说明折叠。
