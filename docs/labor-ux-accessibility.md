# 劳动工具独立 UX 与可访问性审阅

审阅日期：2026-10-12。环境：本机 `http://localhost:3000/#labor`，独立 Chrome 标签，桌面 1680×943、手机模拟 390×844 与 320×740。仅使用网页与虚构示例数据。先独立体验页面，未读取实现或既有验收脚本；随后读取 `docs/DEVELOPMENT.md`，未发现适用 AGENTS.md。此为模拟专业审阅，不是真实用户群测试，也不是完整 WCAG 认证。

## 改版前结论：有发布阻断

不能以“无横向溢出”“字段有标签”判定可用。任务入口、动作与主结论被长表单及重复说明掩盖，复现了“不知道怎么填、哪里是结论”的问题。

## 操作与可访问性证据

1. 新开独立标签访问指定 URL，发现首页，点击侧栏工资入口；观察桌面首屏。主按钮不在首屏，需要向下寻找。
2. 空表点击“计算工资与成本”，出现“暂不能计算，请确认适用……”；DOM 只读检查证实错误 `role=alert`，焦点保留提交按钮。
3. 点击“一键虚构示例”：15000 税前、2000 个人缴费、4000 单位缴费；生成税额240、实发12760、单位成本19000。此处仅记录界面显示，未做法律/公式审计。
4. 切到390宽观察首屏、主按钮与结论距离；点击计算后结果标题在按钮下，但其下仍是长免责与范围文字，而非主金额。
5. 提交后按 Tab 焦点到“重置”，截图可见焦点轮廓；结果容器有 `aria-live=polite`。未进行真实屏幕阅读器播报验证。
6. 切到320宽，点击工资标签，按右方向键能切到养老，再按右键能切到规则；tab 的 selected 和 roving tabindex 随之更新，焦点轮廓清楚。
7. 表单标签在 AX 树具有可读名称；长说明关联在多个输入的可访问名称/描述中。规则页可通过键盘工作区选择抵达，官方链接名称可读。全局免责可见。未点击外站或传输任何真实参数。
8. 两种窄屏均没有横向溢出；这是布局检查通过，不抵消上表可用性阻断。

## 改版后独立复测（2026-10-12）

采用新建 Chrome 标签、重新从任务选择开始的实际体验；未读实现、未采用实现方点击脚本。桌面 1680×943、390×844、320×740。实测工资、退休日期、养老缴费单项及导航；未扩展到所有任务的全量数值、所有错误分支或外站链接内容审计。

### 结论和前后变化

原有“任务混排、动作不可找、结论埋在重复规则后”阻断已解除。新版先选择一个问题，再展示该任务的输入；工资/年度汇算、退休日期/领取省/养老金金额/单项/分段不再同页排成长表。计算结果聚焦、主数放大，官方来源与 AI 提示未被一并隐藏。

| 基线编号 | 复测状态 | 证据 |
| --- | --- | --- |
| UX-A1 P1 | 关闭 | 320 下任务入口进入后可见“先看虚构示例”，底部“计算到手工资”固定可达（视口 Y=686—730）；工资示例自动聚焦结果，无需滚三屏找结论。 |
| UX-A2 P1 | 关闭 | 工资结果首先显示税后12760，390和320均完整可见；详情默认折叠，两个直接官方来源与AI摘要可见。示例按钮到结论只需一次点击，任务页到示例也是一次。 |
| UX-A3 P2 | 关闭 | 养老各任务独立选择，320退休示例整页约2340px，相比旧版同时挂载五任务9948px显著减少；不能据此认定所有复杂表单都已最短。 |

### 新版自主操作记录

1. 冷开指定 URL，等待真实页面稳定后看到8张任务卡。桌面三列、320两列，所有卡题与开始入口可读；320首屏可看到工资、单位成本、年度汇算、退休四个入口。
2. 点工资任务后进入独立表单，焦点在“当前任务导航”。点击“先看虚构示例”直接看到12760主金额，焦点落在结果容器。390结果标题视口Y=329，主要金额位于其下可见范围，页面总高约2666px；首要改进是自动定位结果，不只是减少页高。
3. 320下重复示例与计算，主金额未被顶部116px导航或计算动作遮住。填写阶段按钮固定在底部，结果阶段动作留在结果上方；未观察到无法滚动到的输入或被永久覆盖的来源/免责。
4. 从结果按Tab，下一站为“累计预扣规则”直接来源；展开/收起“计算明细、假设与全部规则依据”可用，收起后仍保留主金额、直接来源和AI提示。展开“完整提示”可找到不构成税务/社保/法律意见、主管部门核定与固定养老金情景说明。
5. 重置清空金额、确认项和结果；空表计算聚焦错误，提示先确认本单位此前是否发薪。再次载入示例后把税前工资改为abc：旧结果立即消失、示例标记消失、两确认项取消。重新确认后计算，错误点名税前工资及合法格式。错误容器可见且role=alert，但字段自身未标aria-invalid（P3）。
6. 将税前工资改为虚构16000并重新确认后计算，主结论变为“本期预计到手”13730，焦点正确落结果。无旧示例结论残留。
7. 返回任务选择后重选工资，草稿与结果保留，与页脚提示一致。任务导航后的纯键盘顺序为Tab返回任务、Tab任务下拉、Tab示例，Enter可以生成并聚焦结果。
8. 在320下自主切换退休任务并载入示例，结果2025-02、60岁1个月、15年最低要求清楚，直接来源存在；非整周岁不算金额的后续限制有可见说明。再切养老缴费单项，示例581.60与1163.20分两卡显示，不混成一个工资或养老金总额。
9. 刷新后回到劳动任务选择；进入工资确认草稿清空。切换全站工具到时间戳，浏览器后退返回劳动任务选择，URL与内容一致。刷新可能恢复旧滚动位置，落在任务列表中下部，属于P3改善项。
