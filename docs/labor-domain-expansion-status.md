# 2026-10-12 本地覆盖扩展

规则版本 `2026-10-12.3`。本版本按已核验范围发布；具体生产状态以部署记录为准。两入口验收通过不表示全国综合计算需求已经完成。

## 已实际扩展

- 上海工资：移除8000—15000与整百门槛；当前工资按分，上年均薪暂按整元，逐项映射法定上下限。住房税限以有理数交叉相乘判断；失业半分、公积金非整元等未知地方尾差只阻断相应项目。个人缴费超过工资会显示现金缺口，不伪造负到账。
- 上海养老：未来基数7546—37731元整元，三档仅例子；总月数不再限3的倍数。未知四位取舍分别计算相邻上下界，分项进角一致才给确定单值，否则显示待核范围。历史扩至1993；2014年前须明确核定逐月指数和已含法定历史保底。
- 目标倒推：基数双二分门槛与全部30186个整元基数独立穷举一致。月数逐一判断；不确定候选不清空其他已证明的可行方案。门槛/最低金额/已知可行方案分开，不能把首卡说成全局最低。原计划严格符合本次窗口、制度、范围和预算且精确达标时，保留并标记其候选；超预算等条件不符不冒充原方案可用。2000/10000/20000只是目标预填。
- 北京、浙江含温州：经办核定标准基础养老金 `B × 全部核定年限 × 1%` 的独立复核可含普通中人及已认定视同，不再限15—28年；新增单独确认，仍只收两位年限、结果恰到角。账户范围不跟随扩大；未知、双低等特殊公式拒算，不输出过渡、补贴或总待遇。
- 缺失历史现金：完整累计断线并显示未知区域，已录部分另用点线标注，绝不补零。历史指数和账户资料帮助明确应向官方经办核对，不冒充存在自动取得精确指数和的接口。

- 浙江/温州：2026医疗配套及实际降费、医疗基数、失业单位续期、长护/大病当期资金安排；养老金调节金、最低补足与完整尾数链。个人医疗2%旧正式办法已取得，但新配套冲突未排除，未将它注册为当期可算规则。见 [浙江温州补证](labor-wenzhou-20261012-evidence-update.md)。
- 跨省金额、居民/机关事业/其他特殊制度、历史指数重建、未来政策和利息预测仍未开放。领取年数仅累计观察窗口，计发月数独立。
