# 二次开发

## 环境

- Node.js `22.22.0`，以 `.nvmrc` 为准；也支持 `package.json` 声明的 Node.js 24 及以上版本。
- npm，依赖版本由 `package-lock.json` 锁定。

```bash
nvm use
npm ci
npm run dev
```

默认访问 `http://localhost:3000/`。当前版本无需环境变量。

移动端布局约定、PC 设备模式、手机局域网访问与真机调试见 [移动端适配与调试](MOBILE.md)。

## 新增一个工具

1. 在 `components/` 新建工具组件，界面文案优先中文。
2. 将可独立验证的逻辑放进 `lib/`，避免把计算和 DOM 操作混在一起。
3. 在 `lib/tool-catalog.ts` 的 `ToolId` 与 `tools` 注册表中登记名称、描述、关键词和 `category`：`development`（开发工具）、`calculation`（计算工具）或 `market`（行情）。首页、桌面导航与手机选择器共用这里的分类，`kind` 独立表示本地处理或第三方行情。
4. 在 `components/toolbox-app.tsx` 的 `activeWorkspace` 中连接组件；工具入口使用稳定的 Hash ID。
5. 在 `tests/` 增加正常路径、主要错误路径和关键边界测试。
6. 更新 README 的工具清单；若改变数据流或运维边界，同步更新架构和运维文档。

## 开发约定

- 页面保持极客、简洁、中文优先；只在必要名词中保留英文。
- 复用全局颜色、间距和控件样式，工具专属复杂样式可使用 CSS Module。
- 数据处理默认 local-first，不把用户内容发往服务端。
- 浏览器持久化只存少量偏好；调整 key 或数据结构时使用版本后缀并提供兼容策略。
- 外部服务必须在界面明确标注来源、延迟和隐私边界。
- 错误信息应告诉用户如何修正输入，不静默吞错。

## 行情开发

- 默认自选与代码规范化位于 `lib/market-symbols.ts`。
- 固定标的应保存明确的 `EXCHANGE:SYMBOL`，避免同名代码落到错误市场。
- 简洁模式不得挂载蜡烛图 iframe；用户主动进入专业模式后再加载。
- 新的自选字段必须保持可序列化，并限制数量和输入长度。
- 自选顺序就是数组顺序；币价和美股分别持久化，旧版 key 只读迁移，不在新版继续写入。
- 九神指数只使用 Binance 已收盘 UTC 日线；经典口径、缓存版本和阈值逻辑位于 `lib/ahr999.ts`。

## 本地缓存

- 复利只缓存输入参数、币种和现金流，不缓存计算结果；恢复时重新生成现金流内部 ID。
- 复利缓存写入 `zy5-tools-compound-v2`；该键不存在时读取旧版 v1，旧现金流恢复为固定金额，随后只写 v2。新版缓存必须保留计量方式，不把百分数当作金额。
- JSON 阅读器只缓存原始草稿，有效内容恢复时重新解析；非法草稿也保留，但不会伪造解析结果。
- JSON 草稿上限为 100 万字符，超过后明确提示未缓存，避免同步存储拖慢页面。
- 组件首屏使用固定默认值，挂载后再读取 `localStorage`；完成读取前禁止写入，避免覆盖已有缓存。

## 复利开发

- 现金流计划由方向、计量方式、数值、开始月、持续月和周期间隔组成。`amountType` 为 `fixed` 或 `percentage`；`amount` 分别表示货币金额或百分数，例如 `2` 表示 2%。切换计量方式时数值归零，由用户重新输入。
- 百分比范围为 0–100%。先把资产按原复利口径增长到执行月，再以当时的资产计算现金流；百分比投入表示从外部追加资金。
- 同一时点所有计划共用执行前的资产基数，与计划排列顺序无关。例如当时资产为 10,000，同时固定投入 1,000、按 2% 拿走，分别执行 1,000 和 200，执行后为 10,800。
- 百分比基数为 `max(0, 当前资产)`；资产不大于 0 时，百分比投入和拿走均为 0，避免现金流反向。固定金额计划仍可恢复余额或继续形成资金缺口。
- 持续区间采用半开区间；投资终点当天发生的现金流仍计入结果。
- 投入与拿走允许重叠，负余额表示计划资金不足。
- 收益恒等式为：最终价值 + 累计拿走 − 累计投入。
- 累计投入与拿走按各期实际执行金额累加；图表采样数量不影响现金流执行与最终计算结果。
- `periods` 与结果共用计算过程，记录每期的期初资产、计息后资产、实际现金流、收益和执行后余额。第 0 期只含立即执行的计划；后续各期包含上期末之后到本期末（含当天）的现金流，尾部不足整月不提前执行下一月计划。
- 图表按 `periods` 绘制和选择月份；悬停与滑块共用所选期，鼠标离开后保留明细。计划占比以该期执行前资产为基数，基数不大于 0 时标为不适用。

## 提交前验证

```bash
npm test
npm run lint
npm run typecheck
npm run check
npm run build
git diff --check
```

最低验收还包括：

- 首页、任一纯本地工具和两个行情页可打开。
- 刷新后 Hash 路由仍定位到当前工具。
- 复利参数与 JSON 草稿在切换工具或刷新后保持。
- 行情搜索可加入、删除和调整自选顺序，刷新后保持。
- 简洁模式只有行情总览，专业模式才出现蜡烛图。
- 九神指数能加载已收盘日线；断网且已有缓存时继续显示上次结果。
- 桌面端和窄屏没有横向溢出。
