# 工资与养老工具

入口：`https://tools.zy5.dev/#labor`。规则版本 `2026-10-12.1`，本轮核验日 `2026-10-12`。AI 辅助制作，仅供参考；不构成税务、社保或法律意见。请自行查阅所附官方规则并复核计算，实际以主管部门核定为准。

## 首版可用范围

| 功能 | 范围与输入责任 |

| 领取省份判断 | 2026-10-12规则快照；仅大陆户籍、尚未领待遇、普通企业职工同制度、完整普通关系已核定且已达待遇条件。按户籍关系、现关系省120月、最近满120月省、户籍归集四分支。浙江各市合为同省，不能输出温州市级经办地。 |

领取窗口只是固定月金额的算术累计期间，不是养老金截止期限、不是计发月数，不包含未来待遇调整、个人账户利息、工资增长或生存概率。

## 交互与结果

入口先选择要解决的问题：到手工资、单位成本、年度税、退休日期、领取省份、养老缴费单项、养老金情景或分段预算。每次只展开一个任务；任务之间保留本工具内的内存草稿。退休日期和领取省份可以交接到金额情景，但不替代经办资格确认。

提交后直接定位主结论或可修正的错误。每个主结论附官方原文链接，公式、适用人群、有效期、核验日及完整来源在结果明细中展开。虚构示例明确标注；修改示例条件会撤销旧结果与适用确认，未知值不能用0替代。

改版的独立新手任务记录见 `labor-ux-salary.md`、`labor-ux-province.md`、`labor-ux-accessibility.md`。这些是AI模拟审阅，不是真人实验或完整无障碍认证；是否通过以各报告最新复测结论为准。

## 明确未开放

- 上海、北京、浙江温州、深圳完整自动缴费包：虽然已取得部分2026官方基数和比例，仍缺完整地方舍入、实际工伤浮动、特殊缴存条件等证据；所有依赖缺项的自动合计拒算。规则入口不能把人工金额模式宣传为支持全城法定缴费。
- 经办关系自动认定、临时账户和历史指数重建。普通关系省级判断不代替行政核定；已有待遇、港澳台/外籍、户籍迁移、组织调动、2010年前转移遗留、重复欠缴等特殊情形拒判。不将各省养老金相加，不把转入全国总年限当某省当地缴费年限。
- 居民制度、机关事业、特殊工种、病残、视同缴费、过渡性待遇、一次性补缴及非整周岁计发月数。
- 非居民工资、经营所得、单独计税奖金、免税/减免税、首次就业特殊扣除、上年低收入简化预扣、境外税额抵免。实际个人缴费不自动全部抵税。

## 证据与实现

- `lib/labor-rules.ts`：版本、公开来源、规则覆盖矩阵、逐字段映射与参数。来源有发布/生效/截止（未规定时为空）、核验日、人群和旧文说明。数据有效区间与工具技术覆盖区间在界面区分。
- `lib/labor-engine.ts`：整数分，税额与养老金使用有理数/BigInt处理舍入，月中规则不无条件覆盖整月；缺来源、无适用规则和明显矛盾输入拒算。每个最终结果携带公式、来源ID和适用范围。
- `lib/labor-ledger.ts`：独立金额预算，不计算或改变参保权益。
- `lib/labor-benefit-province.ts`：省级四分支与严格输入前置检查；不输出待遇金额。
- `lib/labor-contribution-item.ts`：已核定整数元基数上的养老单项；不猜舍入，不夹取或四舍五入非法基数。
- `tests/labor-*.test.ts`：实施测试与独立手算测试分离，覆盖真实发布规则、缴费边界和跨省先后。
- `docs/labor-research-*.md`：上海、广东、北京、北京养老金、浙江温州及跨省规则证据与未闭合缺口。研究未通过的字段不得进入计算规则。
- `docs/labor-independent-audit.md`、`docs/labor-browser-audit.md`：独立审核与浏览器实际验收记录，以记录状态为准。

## 隐私与后续维护

只在本地浏览器内存处理；不存真实薪酬、不请求计算API、不上传出生日期和账户。没有导出/分享功能。官方链接由用户主动打开且不携带输入。

规则更新需保留旧版本适用期、引用原文和核验日，独立复算黄金向量后再启用。下一阶段优先补地方缴费舍入、公积金完整时间分段和工伤行业/浮动确认，随后才开放自动地区包；不通过猜测费率扩大覆盖。
