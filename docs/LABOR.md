# 工资与社保退休金：支持范围

规则版本：`2026-10-12.3`。核验日：2026-10-12。本文说明本版本的计算能力；实际生产版本以部署记录为准。

两个主入口是“工资测算”和“社保退休金测算”。它们用于核对已支持的缴费项目、比较固定参数情景，不提供全国全人群的完整工资或养老金计算。资料未知保留未知，规则缺失逐项拒算，不用零或统一免责声明补齐。

AI 辅助制作，仅供参考；不构成税务、社保或法律意见。请自行查阅所附官方规则并复核计算，实际以主管部门核定为准。

## 工资测算

从城市与税前月薪开始；上年月均工资暂同当月、公积金各5%是可调整的明示情景，不是法律默认或已核事实。个人与单位分列，完整结果、已算小计、现金缺口各有明确名称。

| 地区 | 本版本开放 | 尚未开放或必须补充的条件 |
| --- | --- | --- |
| 上海 | 普通职工个人缴费；固定2026-10规则重复12期的年均净现金情景。当前工资支持分，上年月均暂支持整元，公积金各5/6/7%，按已核基数上下限映射。单位已核项目单列。 | 单位失业、工伤缺项，不输出完整公司成本。失业不足分、公积金非整元等未知取舍阻断相应项目；个人缴费不完整或超过工资时不输出完整税后。补充公积金、特殊减免及未核税扣不自动套用。 |
| 北京 | 普通缴费精确子域内个人与单位项目；填写并确认本期最终工伤费率后，可在各项齐全时输出工资加法定单位缴费的标准成本。限定零税证明域可作12期净额比较。 | 工伤率真实输入初始未知。一般正税净额所需大额互助税扣及独立公积金税限证据未闭合；零税证明失败不等于断言实际应缴税。额外福利等支出不自动包含在标准成本中。 |
| 温州 | 个人养老与双方公积金等已核项目；公积金按县区适用范围判断。 | 不提供完整五险一金、税后或公司成本；医疗、失业、长护等当期证据缺口不得用其他地区参数补齐。 |

上海不再使用8000—15000或整百工资门槛。保留的逐项精度要求是产品支持子集，不是法定工资范围。个人缴费超过工资时保留缴费明细并显示正数现金缺口，不输出负到账金额。

默认年均税后是同一当前规则、同一工资与缴费重复12期、无额外收入和扣除的比较，**不是本月实发，也不是实际2026年度汇算**。年净额除以12的展示值可能近似，明细保留全年值和计算口径。高级单独基数覆盖不直接进入税后比较。

真实累计预扣、税后反推、年度汇算及已核单位成本对账有独立输入。实际个人扣款与依法可税前扣除金额分开；税后反推须固定月份、前期累计背景和缴费条件。普通预扣不涵盖首次就业、免税减免、特殊简化预扣等未实现口径。

## 社保退休金测算

先填个人情况，再在同一时间线上记录历史与未来。退休日期、缴费年限条件、领取省和金额分别判断：能算日期不等于已认定完整领取资格，也不等于能算金额。

| 能力 | 适用边界 |
| --- | --- |
| 法定退休年月 | 出生年月及档案确认的原50/55/60岁类别；不能仅凭性别推定。规划主流程不优化弹性提前、延后或特殊退休。 |
| 领取省条件核对 | 完整已核普通养老关系、户籍、各省认可月数与先后顺序；按法定分支核对至省级。临时账户及特殊转移等不自动判断，不把温州当独立省，不拼加各省养老金。 |
| 上海金额规划 | 同省普通实际缴费，历史可从1993年起；排除视同、过渡及特殊公式。输入经办核定的逐月四位指数之和、认可月数和截至2026-09的账户余额；不能用已舍入平均指数反乘月份。2014年前另须确认指数和已按2026附件处理历史保底。 |
| 未来缴费 | 冻结2026规则，基数7546—37731元整元，12577等仅为例子；职工个人8%、单位16%，灵活本人20%与账户入账8%分开。灵活身份另有准入确认及退休月条件，不与职工制度混算。 |
| 金额精度 | 支持已核50—66整岁计发月数，不为非整岁插值。总月数不再限3的倍数；四位指数、折年取舍分别求上下界，分项见分进角后相同才给单值，否则仅给“取舍待核范围”。 |
| 固定未来情景 | 使用2026参数、12577元工资分母、未来增长0和账户利息0；假设符合条件并在退休月办妥手续，次月领取。不是未来政策预测、保底待遇或经办核定。 |
| 目标倒推 | 锁定个人情况、历史和账户，只求固定基数下缴多久，或固定窗口内整元基数；受个人月预算和退休时间约束。2000/10000/20000元仅为目标预填。采用方案明确替换未来计划，其余未来月份停缴。 |
| 未知与可行性 | 资料不足不是无解。已有精确可行方案与最低投入是否确定分开；敏感范围不可采用，也不把首张候选一概称为最优。最高可达只针对本次规则、预算及搜索域。 |
| 现金图与累计 | 月度与累计图共享年月轴，个人、单位和养老账户口径分开。历史现金未知时断线并标未知，未来已录部分用独立点线，不补零。领取年数仅观察窗口，不是法定停发期限，也不是计发月数。 |

北京、浙江（含温州）另有**已核参数的养老金单项复核**：标准基础分项 `B × 全部核定年限 × 1%` 经明确确认后，可含普通中人及已认定视同年限，不再限15—28年。B是经办已处理的计发工资中间值，不是月薪、社平工资或缴费基数。双低等特殊公式、过渡、调节金、补贴、最低补足和总额不计算。账户分项仍保留原普通新人及整岁、精度范围，不随基础分项扩大。

## 其他按需工具

- 北京普通企业与温州适用县区公积金单项；温州限定灵活缴存另核身份、无未结清公积金贷款等条件。基数整数元是本版输入精度，不宣称法规只允许整数元。
- 北京限定档案机构、街道乡镇等适用渠道的个人三险；养老和失业共用已核定基数，医保按已核固定月额。参保组合是已有核定状态，不暗示可任意退保；未知状态拒算。
- 北京、上海、浙江限定养老缴费单项，以及实缴或显式假设月额的分段预算。预算不认定账户权益，不把职工、灵活或居民不同制度合成待遇。

## 来源、隐私与验证

每项最终结果都有自己的依据入口，可展开公式、地区、人群、适用期、核验日及完整官方链接。规则数据和字段来源在 `lib/labor-rules.ts` 版本化维护；未知日期不编造，政策快照与法律有效期分开。

工资、出生年月、历史和账户等输入仅驻留页面内存，不上传、不持久化、不放入链接；示例均为虚构。官方链接仅由用户主动打开，不携带输入参数。编辑适用范围或事实会撤销相应确认和旧结果。

本版本完整项目323项测试及60组独立审核通过，另经桌面和320/390宽度交互验收。验证的是已登记范围，不代表全国覆盖或主管部门认可。
