## 准入边界

- 事实、已核规则、未来假设分别表达；未知历史指数、权益或账户截止月不得转0。停缴为0与没有记录不同。
- 现金额模块只支持2026退休。未来可有明确的“2026公式冻结比较”范围，但不能改未来退休年份绕旧闸门；出生改革和2030最低年限仍按真实退休年月判断。
- `unsupported`为来源或资料不足；`infeasible`只能用于完整且已穷尽搜索域的数学无解。
- 倒推只改未来，历史地区/制度/年月/基数/实缴/账户与截止月不可变。每个候选必须正向复算，重新核退休资格和领取省。
- 每项输出保留公式、地区、人群、年份、期效、核验日及可点击官方原文。

## 京浙基础分项复核扩域：只扩大标准算式，不扩大待遇认定

本轮独立 web 打开[北京京劳社养发〔2007〕21号](https://www.beijing.gov.cn/zhengce/zhengcefagui/qtwj/200804/t20080414_567066.html)，门户标有效，二（一）标准基础养老金明确按全部缴费年限含视同计算，二（三）过渡分项另列，三明确2011起不再新老对比。因此旧新人15–28年不是基础公式本身的法定适用边界。
